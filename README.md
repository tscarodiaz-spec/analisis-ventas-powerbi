# Análisis de Ventas - Power BI

## Descripción
Proyecto de análisis de datos enfocado en el comportamiento de ventas, utilizando Python y Power BI.

## Herramientas
- Python (Pandas)
- Power BI

## Análisis realizado
- Limpieza y transformación de datos
- Análisis de ventas por categoría y segmento
- Tendencia de ventas en el tiempo
- Análisis de clientes (Top 10 y Pareto)

## Resultados
- Crecimiento sostenido de ventas desde 2016
- Mayor participación del segmento Consumer
- Concentración moderada de clientes

## Archivos
- Dashboard en Power BI
- Dataset utilizado
- Código de análisis en Python
